# History Pieces 와이어프레임 통합본 (2026-08-07)

## 실행

Windows에서 `RUN_ONE_CLICK.bat`을 더블클릭합니다. Python과 모델 실행 환경이 이미 있으면 기존 AI 모델 서버로 실행하고, 없으면 Windows 기본 PowerShell 로컬 서버로 자동 전환됩니다. 다른 PC에서도 TimeTrace를 보기 위해 Python이나 Node.js를 따로 설치할 필요가 없습니다.

브라우저가 자동으로 열리지 않으면 `http://127.0.0.1:5517`로 접속합니다.

`index.html`을 직접 열지 마세요. 반드시 `RUN_ONE_CLICK.bat`을 실행해야 ES 모듈과 JSON을 사용하는 TimeTrace가 정상 작동합니다. Python과 모델 패키지가 있는 PC에서는 직접 학습 PTH 모델도 함께 연결됩니다.

## 이번 통합 범위

- 제공된 화면 와이어프레임의 진행 순서를 기존 통합본 UI에 연결했습니다.
- 기존 색상, 폰트 규칙, 모바일 규격, 배경, 카드, 버튼, 다국어·추천·여정필름 코드를 유지했습니다.
- 사진 선택 후 확정, 장소 확인, 실제 TimeTrace, 조각 획득, 웹툰, 5초 기록 확인, 감상 선택, 다음 장소 이동 순서를 적용했습니다.
- 조각 1은 MST(목포역), 조각 2는 HNB(목포 대중음악의 전당 → 호남은행 목포지점), 조각 3은 MMH2(목포근대역사관 2관 → 동양척식주식회사 목포지점) TimeTrace 자산을 사용합니다.
- 조각 1·2·3 모두 장소 확인 완료 직후 TimeTrace가 실행되며, 완료 후 조각 1은 획득 화면, 조각 2·3은 와이어프레임의 돌발 미션으로 연결됩니다.
- 두 번째 조각의 호남은행 기록 찾기와 세 번째 조각의 위조 기록 찾기 돌발 미션을 적용했습니다.
- 최종 퀴즈 정답 흐름을 `B → C → A`로 적용했습니다.
- 조각 1·2·3 웹툰은 `addons/webtoon-reference/piece-1~3-style.jpg` 로컬 고정 이미지로 표시합니다.
- 고정 웹툰은 각 조각의 웹툰 화면에서만 표시되며 샘플 사진·촬영 확인·타임트레이스·장소 이야기·여정필름에는 전달되지 않습니다.
- 첫 장소 및 조각 1·2·3의 샘플 진행은 별도 이미지 파일을 사용하지 않고 `🖼️ 샘플 사진` 표시로 동작합니다.
- 출처가 확인된 실제 과거 사진이 없는 경우 웹툰 이미지를 대신 넣지 않고 `옛 기록 자료는 아직 연결되지 않았습니다` 안내를 표시합니다.
- Gemini·생성형 웹툰 API·API 키 파일·웹툰 생성 대기 화면을 제거했습니다.
- 직접 학습 PTH 장소 판별 API는 그대로 유지했습니다.
- 장소 이야기 웹툰에 조각 사진 세 장을 합성하는 기능은 요청대로 이번 통합에서 구현하지 않았습니다. 현재 장소 이야기 템플릿은 그대로 유지됩니다.

## 주요 파일

- `addons/wireframe-flow-0807.js`: 와이어프레임 화면 순서와 추가 화면
- `addons/timetrace-host-0807.js`: 세 조각과 MST/HNB/MMH2 TimeTrace 연결 및 완료 후 분기
- `addons/timetrace/`: TimeTrace 코드, 설정, 승인 이미지·영상 자산
- `addons/fixed-webtoon-runtime-0807.js`: 조각 1·2·3 고정 웹툰 연결
- `addons/integrated-ui-0725.css`: 기존 디자인과 추가 화면 반응형 스타일
- `run_integrated.py`: 정적 화면 제공과 PTH 장소 판별 API
- `verify_integrated.py`: 파일·구문·연결 상태 검사
- `RUN_ONE_CLICK.bat`: 실행 환경을 자동 감지하고 서버를 시작하는 원클릭 파일
- `START_NO_INSTALL.bat`: Python·Node.js 없이 TimeTrace와 전체 샘플 흐름을 실행하는 파일
- `tools/static_server.ps1`: Windows 기본 기능으로 정적 자산·영상·TimeTrace 모듈을 제공하는 로컬 서버
