다음 작업을 현재 History Pieces Git 저장소에서 수행해줘.

목표
- `HistoryPieces_0809_GitHub_Changes.zip`의 변경 파일만 현재 통합 브랜치에 안전하게 반영한다.
- 기존 AI 모델, TimeTrace 자산, 고정 웹툰, 중국어 흐름과 사용자 변경 사항은 보존한다.
- PDF UX 보완 화면과 대표 시나리오 연결을 검증한 뒤 커밋하고 GitHub에 올린다.

반드시 지킬 원칙
1. 먼저 `git status`, 현재 브랜치, 저장소 루트, 최근 커밋을 확인한다.
2. 작업 트리에 기존 변경이 있으면 삭제하거나 되돌리지 말고 목록과 충돌 가능성을 먼저 보고한다.
3. `codex/historypieces-pdf-ux-0809` 브랜치가 없으면 현재 통합 브랜치에서 새로 만든다.
4. 변경 ZIP을 임시 폴더에 풀고 `CHANGED_FILES_0809.txt`에 적힌 파일만 저장소의 같은 상대 경로에 반영한다.
5. ZIP에 없는 파일, 모델 파일, 팀원 작업 파일은 수정하지 않는다.
6. 생성형 웹툰 API나 임의 역사 사실·거리·사진·URL을 추가하지 않는다.
7. 공식 사진이 없는 추천 후보의 자리표시자는 그대로 둔다.
8. 최종 퀴즈 코드는 보존하되 대표 흐름이 전체 이야기에서 여정필름으로 이동하는지 확인한다.

Git 작업
- 검증 실패 시 커밋·푸시하지 말고 원인과 영향을 보고한다.
- 통과하면 실제 변경 파일만 `git diff --stat`와 `git diff --check`로 다시 확인한다.
- 커밋 메시지: `feat: integrate PDF UX flow and journey rewards`
- 원격 저장소가 정상 연결되어 있으면 현재 브랜치를 push한다.
- GitHub CLI 인증이 있고 권한이 있으면 이 브랜치에서 통합 브랜치로 향하는 Draft PR을 만든다.
- PR 제목: `PDF UX 보완 화면 및 대표 시나리오 통합`
- PR 본문에는 구현 화면, 변경 파일, 검수 결과, 공식 사진 자리표시자 잔여 항목을 정리한다.
- 마지막에 브랜치명, 커밋 해시, push/PR 결과, 검증 결과, 실제 변경 파일 목록을 보고한다.
