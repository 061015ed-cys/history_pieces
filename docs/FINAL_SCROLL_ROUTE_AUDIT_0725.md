# 언어·국가 스크롤 및 추천 경로 최종 검수

수정 범위는 `addons/integrated-ui-0725.css`뿐입니다. 공통틀의 `index.html`, `style.css`, `script.js`와 기존 모듈은 수정하지 않았습니다.

## 수정 내용

1. 언어 선택 화면의 목록 카드 내부 스크롤 복원
2. 국가 또는 지역 선택 화면의 목록 카드 내부 스크롤 복원
3. 추천 장소 카드에서 `목포역 → 추천 목적지`가 카드 안에 항상 들어오도록 폭과 줄바꿈 보정
4. 모든 추천 후보에 같은 경로 구조 적용
